# Contributing to Custom Domain DNS

We love your input! We want to make contributing to this project as easy and transparent as possible.

## Development Process

1. Fork the repo and create your branch from `main`
2. If you've added code that should be tested, add tests
3. Ensure the test suite passes
4. Make sure your code lints
5. Issue that pull request!

## Pull Request Process

1. Update the README.md with details of changes
2. Update the CHANGELOG.md with notes on your changes
3. Increase version numbers in package.json files
4. Your PR will be merged once you have the sign-off

## Coding Style

- Use 4 spaces for indentation
- Use camelCase for variables and functions
- Use PascalCase for classes
- Add comments for complex logic
- Keep functions small and focused

## Testing

```bash
npm test
```

## Reporting Bugs

Use the GitHub Issues tracker and include:
- Summary of the bug
- Steps to reproduce
- Expected behavior
- Actual behavior
- Screenshots/logs if applicable

## Feature Requests

Use GitHub Discussions to suggest new features.

## Questions?

Open an issue with the `question` label.
